# Algas

## Cianobacterias (Algas Verdeazules)

| Característica           | Descripción                                                                                                              |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| Organización celular     | Procariotas                                                                                                              |
| Pigmentos fotosintéticos | Clorofila a                                                                                                              |
| Pigmentos accesorios     | Ficobilinas                                                                                                              |
| Cubierta celular         | Vaina mucilaginosa + pared celular de peptidoglucano                                                                     |
| Sustancias de reserva    | Almidón de las cianofíceas, gránulos de cianofíceas y gránulos de polifosfato                                            |
| Reproducción             | Asexual: fragmentación (formación de hormogonios)                                                                        |
| Estructuras              | Acineto (reproducción) y heterociste (fijación de nitrógeno)                                                             |
| Tipos de talo            | Unicelular, colonial, filamentoso no ramificado, filamentoso ramificado, filamentoso falsamente ramificado, tricotálicos |

## Chlorophyta (Algas Verdes)

| Característica           | Descripción                                                                                                            |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| Reino                    | Plantae                                                                                                                |
| Habitad                  | Acuatico (agua dulce y el 10 % son marinas) o terrestre                                                                |
| Ambiente                 | rocoso, arenoso, manglares, arrecifes coralinos, estuarios, lagunas costeras o comunidades de  pastos marinos          |
| Sustrato                 | adheridas a  rocas, fijarse en raíces o  madera, en la arena o flotando                                                |
| Organización celular     | Eucariotas autotrofos                                                                                                  |
| Pigmentos fotosintéticos | Clorofila a y b                                                                                                        |
| Pigmentos accesorios     | Xantofila: Luteína, β-carotenos y, en sifonáceos, sifoneína y sifonoxantina                                            |
| Cubierta celular         | Escamas (Primitivo) o teca cristalina de glicoproteínas, pared celular de celulosa o de xylanoso-mananos en sifonáceos |
| Sustancias de reserva    | Almidón (en el cloroplasto)                                                                                            |
| Flajelo                  | isocontos, Tipo látigo (lisos sin apéndices), Posición anterior  se anclan al protoplasto por  complejos flagelares    |

### Cloroplastos

| Característica | Descripción                                                             |
| -------------- | ----------------------------------------------------------------------- |
| Membranas      | 2                                                                       |
| Tilacoides     | En grupos de 3 o 6                                                      |
| Forma          | Espiralada, de copa, estrellada, reticulado, laminar, discoidales, etc. |
| Ubicación      | Axial (en el centro) o parietal (cerca de la pared)                     |
| Cantidad       | Uno, dos o varios                                                       |

### Estructuras asociadas al cloroplasto

| Estructura | Descripción |
|-----------|-------------|
| Pirenoide | Región del cloroplasto |
| Estigma | Corpúsculo de pigmentos carotenoides (zona rojiza-anaranjada) |

### Talos

#### Tipos de talo microscópicos

- Unicelular con o sin flagelo
- Filamentoso ramificado o no ramificado
- Colonial tipo cenobio
- Colonial con o sin flagelo

#### Tipos de talo macroscópicos

- Sifonáceo
- Laminar o membranoso

### Desmidiáceos

| Característica | Descripción                                                                                                                           |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| Tipo de talo   | Unicelulares o filamentosos                                                                                                           |
| Estructura     | Formada por dos mitades idénticas llamadas hemicélulas o semicélulas, una región central llamada istmo y una abertura denominada seno |
| Cloroplastos   | 1 o 2 en cada hemicélula                                                                                                              |

## Rhodophyta (Algas Rojas)

| Característica                            | Descripción                                                                                                             |
| ----------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Reino                                     | Plantae                                                                                                                 |
| Organización celular                      | Eucariotas autótrofos                                                                                                   |
| Habitad                                   | La mayoría marinas                                                                                                      |
| Ambientes                                 | rocosos, arenosos, en manglares, arrecifes  coralinos y estuarios                                                       |
| Sustratos                                 | epífitas (sobre algas, pastos  marinos, corteza y raíces de mangle),  epilíticas, epizoicas, vivir en arena o flotando. |
| Pigmentos fotosintéticos                  | Clorofila a y d                                                                                                         |
| Pigmentos accesorios                      | Ficobilinas (ficoeritrina, ficocianina y aloficocianina)                                                                |
| Pigmentos accesorios (¡ALGUNAS ESPECIES!) | beta carotenos o xantofilas                                                                                             |
| Cloroplastos                              | 2 membranas                                                                                                             |
| Tilacoides                                | Aislados con ficobilisomas                                                                                              |
| Cubierta celular                          | Matriz de microfibrillas de celulosa + sustancias gelatinosas (polímeros de galactosa sulfatados y mucílagos)           |
| Sustancias de reserva                     | Almidón de florídeas (almidon rozado)                                                                                   |
| Ciclo de vida                             | Trifásico                                                                                                               |
| Tipos de talo                             | Unicelulares, coloniales, membranosos y filamentosos (axiales o multiaxiales)                                           |
### Cubierta celular
- La pared o cubierta es suave por la gran cantidad de sustancias gelatinosas
- Las algas rojas coralinas presentan carbonato de calcio
- Algunos polímeros de galactosa son agares y carragenanos

### Cloroplastos
Discoidales o estrellados

### Importancia
- Son productores primarios
- Las algas rojas coralinas forman parte de los arrecifes coralinos que son habitad para gran cantidad de organismos
- Protegen a los corales de las olas
- Se utilizan en la industria alimenticia, farmacéutica y de cosméticos 
- Se usan en el laboratorio y también en la industria alimenticia para extraer agar, agarosa y carragenanos
- Uso potencial en la medicina humana por algunos compuestos que son antimicrobianos y antihervíboros

### Ficobilisoma
- Son complejos supramoleculares de  pigmentos hidrosolubles, anclados  al tilacoide
- Son antenas recolectoras de luz
- Con ficobiliproteínas o ficobilinas: ficocianina, aloficocianiana,  ficoeritrina.

### Organización del talo
- La mayoría de los talos son filamentosos
- Casi todas las formas son el resultado de agrupaciones de filamentos en arreglos pseudoparenquimatosos
- Los talos de algas rojas pueden tener dos tipos de crecimiento  1. Difuso: las divisiones celulares ocurren en cualquier célula del talo  2. Apical: una célula apical que sufre divisiones y origina nuevas células  y alarga el talo.

### Tipos de talo
Los talos pueden ser:
- Uniseriados: aquellos formados por una célula o por una hilera de células (talos simples)
- Multiseriados: presentan células o filamentos agrupados y compactos, de vista superficial se observan varias hileras de células (talo complejo)

## Ochrophyta (Algas Pardas)

| Característica           | Descripción                                              |
| ------------------------ | -------------------------------------------------------- |
| Reino                    |                                                          |
| Organización celular     | Eucariotas                                               |
| Pigmentos fotosintéticos | Clorofila a y c                                          |
| Pigmentos accesorios     | Fucoxantina, vaucherioxantina y β-carotenos              |
| Cloroplastos             | 4 membranas (2 provenientes del retículo endoplasmático) |
| Tilacoides               | En grupos de 3                                           |

### Bacillariophyceae (Diatomeas)

| Característica        | Descripción                                                                                                                           |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| Cubierta celular      | Frústulo formado por dos valvas superpuestas; la superior es la epivalva y la inferior la hipovalva                                   |
| Sustancias de reserva | Crisolaminarina                                                                                                                       |
| Tipos de talo         | Unicelulares                                                                                                                          |
| Estructuras           | Nódulo central, nódulo polar, rafe, estría, epivalva e hipovalva. Epiteca = epicíngulo + epivalva. Hipoteca = hipocíngulo + hipovalva |
| Células flageladas    | Uniflageladas con pelos tripartitos tubulares (solo en gametos masculinos)                                                            |
| Simetría              | Bilateral (diatomeas penales) o radial (diatomeas centrales)                                                                          |
| Vista al microscopio  | Valvar o cingular                                                                                                                     |

### Phaeophyceae (Algas Pardas)

| Característica | Descripción |
|---------------|-------------|
| Cubierta celular | Ácido algínico (alginatos), polisacáridos sulfatados y celulosa (1–10 %) |
| Sustancias de reserva | Laminarina |
| Tipos de talo | Complejos y filamentosos heterótricos |
| Células flageladas | Dos flagelos heterocontos y laterales |
